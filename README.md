# 🛒 Feira Livre Digital

Aplicação web progressiva (PWA) de e-commerce e marketplace para feiras livres tradicionais, desenvolvida com foco no polo da **CEASA em São Luís, Maranhão**.

## ✨ Funcionalidades Principais

- **Vitrine Dinâmica:** Filtros por categoria (Frutas, Verduras, Legumes, Temperos) e busca em tempo real.
- **Carrinho & Checkout via WhatsApp:** Cálculo automático de taxas de serviço e frete inteligente em tempo real via API OSRM (OpenStreetMap).
- **Painel do Feirante:** Gestão completa de produtos por banca protegida por PIN, acompanhamento de pedidos e **impressão térmica otimizada (58mm/80mm)** com filtro de status em lote.
- **Painel do Administrador Geral:** Aprovação de novos feirantes cadastrados, remoção de produtos e ajuste de taxas do sistema.
- **PWA & Responsivo:** Compatível com dispositivos móveis e desktops, com dados salvos em cache local (`LocalStorage`).
